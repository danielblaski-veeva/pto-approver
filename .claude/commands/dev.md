Start the local dev server for the game:

1. Check whether something is already listening on port 8080. If so, report that the server is already running at http://localhost:8080/ and stop — don't start a second one.
2. Otherwise run `npm run dev` in the background and confirm Vite reports it serving at http://localhost:8080/.
3. If the browser doesn't auto-open, remind me the URL is http://localhost:8080/.
